# Changelog

[Русская версия](CHANGELOG_ru.md)

All notable changes to iDentity Prompt Engine (Music DNA) are recorded here, grouped by commit date.

> **A note on how this file was built.** GitHub's commit messages for this repository are generic ("Add files via upload", "Update en.html") and carry no description of what changed. The entries below were reconstructed from the project conversation and matched to the closest commit date as reliably as possible — they are not read from commit diffs. If a date or an item below is wrong, it should be corrected by hand.

## 2026-09-14

- Coloured palette of `index.html` matched to Airband's: `#FF7F44` accent, `#3A362E` borders, `#E8E6E3` text, `#9E9589` muted text; flat background (no gradient), original layout and markup left unchanged.
- Subheading underline consistency fix: genre-group labels (Rock World / Ethno World / Beyond Rock) given the same bottom-border treatment as the DNA family legends, so every section header looks consistent.

## 2026-09-06

- Added three genres to Rock World: Doomgaze, Shoegaze, Post-Punk.
- Created a new genre group, Ethno World, and moved Slavic Mystic Ethno into it (previously grouped under Rock World).
- Added five further genres to Ethno World: Tribal Ritual Downtempo, Nordic Runic Folk Ambient, Silk Road Mystic, Andean Ceremonial, Celtic Mystic Ambient. A sixth candidate, Shamanic Ritual, was proposed and then dropped.
- Border colour and section-underline adjustments carried out the same day as the genre work above.

## 2026-08-26

- Initial commit: `index.html`, `en.html`, `ru.html` added to the repository.
- `index.html` rebuilt as a language-picker landing page matching Airband's layout parameters (32px/20px page padding, `clamp(44px, 12vw, 64px)` heading, unified spacing down to the language cards).
- Follow-up edits to `en.html` and `ru.html` the same day.
