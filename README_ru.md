# iDentity Prompt Engine — Music DNA

[English version](README.md)

Браузерный инструмент для сборки структурированных промптов для Suno AI из библиотеки составных ДНК-пресетов, жанровых основ и слайдеров эмоциональной интенсивности. Двуязычный (английский/русский), полностью статичный, без бэкенда и зависимостей — всё работает на стороне браузера.

**Линк:** https://imbeyondidentity.github.io/identity-prompt-engine/

## Что это делает

Отмечаешь ДНК-пресеты из одиннадцати семейств инструментов/атмосфер, выбираешь жанровую основу и выставляешь пять эмоциональных слайдеров. Движок собирает выбранное в готовый к вставке Suno-промпт. Те же настройки управляют ещё тремя режимами вывода: брифом текста, дампом MDL-тегов и независимым хьюманайзером.

## Возможности

- **78 ДНК-пресетов в 11 семействах** — Атмосфера/Мир, Гитары, Клавишные, Струнные, Духовые, Синт-лид, Ударные, Бас, Флоу, Вокал, Динамика. Каждый пресет включается галочкой.
- **24 жанровые основы в трёх группах** — Рок-мир (8), Этно-мир (6), За пределами рока (10).
- **Пять эмоциональных слайдеров** — Энергия, Тьма, Мистицизм, Агрессия, Надежда — задают тон промпта и содержание брифа текста.
- **Четыре вкладки вывода** — Suno-промпт, Бриф текста, Хьюманайзер, MDL (сырой тег-синтаксис) — у каждой своя кнопка копирования в один клик.
- **Встроенный хьюманайзер** — убирает ИИ-маркеры из любого вставленного текста (лишние тире, вводные пустышки, канцелярит, промо-язык), независимо от генерации промпта.
- **Сохранённые пресеты** — именуешь и сохраняешь комбинацию ДНК/жанра/слайдеров локально в браузере (`localStorage`); позже загружаешь или удаляешь. Без аккаунта, без сервера.
- **Двуязычный интерфейс** — стартовая страница выбора языка ведёт на полностью отдельную английскую или русскую сборку движка.

## Как пользоваться

1. Открой живую ссылку выше (или `index.html` локально) и выбери язык.
2. Выбери жанровую основу (Рок-мир / Этно-мир / За пределами рока).
3. Отметь ДНК-пресеты из одиннадцати семейств.
4. Настрой пять эмоциональных слайдеров.
5. Переключайся между четырьмя вкладками вывода и копируй результат в Suno.

## Запуск локально

Движок полностью статичный — без сборки, без зависимостей. Либо:

- открой `index.html` прямо в браузере, либо
- подними сервер, чтобы ссылки работали так же, как на GitHub Pages:

```bash
python3 -m http.server 8000
```

затем открой `http://localhost:8000`.


## Структура

```
index.html   стартовая страница выбора языка
en.html      английский интерфейс — вся логика движка и ДНК/жанровые данные
ru.html      русский интерфейс — вся логика движка и ДНК/жанровые данные
```

`en.html` и `ru.html` — каждый самодостаточен (разметка, стили и логика в одном файле), и каждый несёт одинаковый набор функций и ДНК/жанровую библиотеку независимо друг от друга — общего JS-файла между ними нет.

## Ограничения

- **Без бэкенда.** Сохранённые пресеты живут только в `localStorage` браузера: не синхронизируются между устройствами или браузерами, и очистка данных сайта их удаляет.
- **Без билд-пайплайна в этом репозитории.** Правки вносятся прямо в `en.html` / `ru.html`.
- **Только текстовый вывод.** Движок выдаёт текст промпта/брифа/тегов — он не обращается к API Suno и не генерирует аудио сам; результат вставляется в Suno вручную.
